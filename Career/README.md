# Career

Technical skill gets you the interview; this track helps you *land* it. Everything here is tuned for a **career-changer** moving from manufacturing IT & SRE into AI engineering — that transition is a strength when you frame it well.

> **Reframe the narrative:** You're not "someone with no CS degree." You're an **SRE who already ships production automation** (self-healing recovery: 101 incidents auto-resolved) and knows how real systems fail, now adding the AI layer project by project. Lead with that, and only claim AI work once it's built.

---

## When to work on this (per the [roadmap](../ROADMAP.md))

- **Stage 1:** Resume skeleton, plus a running list of work wins with numbers.
- **Stage 2:** Project 1 becomes the first portfolio entry and STAR story. Draft 3 behavioral stories, including the self-healing automation.
- **Stage 3:** Projects 2–3 become portfolio entries and STAR stories. Update LinkedIn as each one ships.
- **Stage 4:** Final resume, GitHub profile and behavioral mocks, then start applying (internal moves first).

Don't leave this to the end. A great resume and portfolio built alongside your learning means you're ready to apply the moment your skills are.
