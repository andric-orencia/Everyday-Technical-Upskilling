# Career

Technical skill gets you the interview; this track helps you *land* it. Everything here is tuned for a **career-changer** moving from manufacturing engineering into AI/ML engineering — that transition is a strength when you frame it well.

> **Reframe the narrative:** You're not "someone with no CS degree." You're an **engineer who already ships AI automation in production**, with real-world operations experience most CS grads lack. Lead with that.

---

## What's here

| Area | Folder | Purpose |
|------|--------|---------|
| **Resume** | [`Resume/`](./Resume/) | A resume that translates manufacturing + self-taught AI into AI/ML-engineer language |
| **Portfolio** | [`Portfolio/`](./Portfolio/) | GitHub profile, portfolio presentation, online presence |
| **Behavioral** | [`Behavioral/`](./Behavioral/) | STAR stories for the "tell me about a time…" round |

---

## When to work on this (per the [roadmap](../ROADMAP.md))

- **Week 1:** Resume skeleton — get the structure down early.
- **Week 2:** Draft 3 behavioral stories.
- **Weeks 4–8:** Each shipped project becomes a portfolio entry + a behavioral story.
- **Week 11:** Finalize resume, polish GitHub & portfolio.
- **Week 12:** Behavioral final pass; start applying.

Don't leave this to the end. A great resume and portfolio built alongside your learning means you're ready to apply the moment your skills are.
